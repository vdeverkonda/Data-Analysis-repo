# Supply Chain Forecasting & Operations Optimization

A GitHub-ready analytics project for Production Data Analyst, Supply Chain Analyst, and Operations Analyst roles.

## Business Problem
Manufacturing sites need accurate forecasts for material demand, production volume, and inventory levels. Poor visibility causes stockouts, excess inventory, waste, and reporting delays.

## What This Project Does
- Cleans and validates supply-chain operational data
- Forecasts material demand using machine learning
- Calculates production and inventory KPIs
- Creates Excel reports for weekly/monthly business review
- Provides a Streamlit dashboard for operational visibility

## KPIs Included
- Material demand
- Production volume
- Waste percentage
- Inventory days on hand
- Forecast error

## How to Run
```bash
pip install -r requirements.txt
python src/preprocessing.py
python src/forecasting.py
python src/kpi_calculations.py
streamlit run src/app.py
```
